# impin v0.1.0 — spec

**impin** ("image pin") — a Wayland layer-shell overlay that keeps reference
images floating above creative tools (Krita, Blender). Local-first, instant
toggle, zero ceremony. Decided in grilling with the owner, 2026-09-27.

## Product shape

- Single binary `impin`. A **resident daemon** owns all pin windows and a
  Unix socket at `$XDG_RUNTIME_DIR/impin.sock`; CLI verbs are socket clients.
  No systemd unit by default (session-scoped; `exec-once` if wanted).
- CLI verbs: `toggle | show | hide | clipboard | add <file> | stop | status`.
  Bare `impin` prints help (owner preference, same as `ua`).
- `toggle` = hide/show **all** pins (global). Hidden pins keep their state;
  re-show restores geometry exactly. `stop` = exit daemon (state saved).
- `clipboard` = new pin from the clipboard image (error message if the
  clipboard holds no image). `add <file>` = new pin from a file. Both spawn
  centered under the cursor. Drag-and-drop of files onto a pin window also
  pins them. A `.desktop` file enables file-manager "Open With → impin".

## Pin windows (Wayland)

- Layer-shell, `Layer::Top`, `Anchor::TOP | Anchor::LEFT`, margin = position
  (fork `Window::set_margin`, tag ≥ .2 **stage-only** semantics),
  `exclusive_zone: -1`, `KeyboardInteractivity::OnDemand` (click-to-focus —
  hover-focus is not a layer-shell capability), transparent background.
- One persistent window per pin; show/hide via `Window::set_visible`.

## Interactions (owner-approved defaults)

- **Move**: left-drag anywhere (barless). **Resize**: 6 px edge strips +
  12 px corner squares (`ResizeDir` with `moves_*`/`active_*` predicates,
  min size). Both use the poll-based ground-truth mechanics proven in
  upperadd (`specs` → vault `20-dragging-panels.md` / `30-resizing-panels.md`):
  offset = −press_local, 16 ms `hyprctl cursorpos` polls, frame-gated
  `set_margin`/`resize` from `render()`, 250 ms pointer-leave grace.
- **Pan**: `Ctrl+drag` or middle-drag; clamped so the image always covers
  the viewport when larger than it (no gaps).
- **Zoom**: `Ctrl+wheel` (×1.25 steps, anchored at cursor) and `-`/`=`.
  Range 0.1×–8×. **`1×` = 100% raster resolution** (SVG: fit size).
  `1` jumps to 100%; `0` or double-click = fit-to-pin. A pin whose image is
  larger than the default size spawns **fit** (whole reference visible).
- **Opacity**: per-pin 0.2–1.0 via `[` / `]` (for tracing over a canvas).
- **Corner radius**: `,` / `.` down/up; max = fully round (circle).
- **Delete**: `Q` or `Delete` on the focused pin. Keys-only in v0.1.
- **Raise**: clicking a pin raises it above sibling pins (implemented by
  re-map if the compositor won't restack layer surfaces — verify on
  Hyprland; fallback = accept map order).
- Pins take keyboard only when focused (click); every critical op is
  mouse-reachable.

## Content

- `PinContent::Image` in v0.1 (`Video` variant reserved; frame-pause etc.
  is v0.2+).
- Formats: PNG/JPEG/WebP/GIF/BMP via the `image` crate (animated GIF/WebP
  animate); SVG natively via the fork; **AVIF** (avif-decode/rav1d) and
  **JXL** (jxl-oxide) decoded in-process → `RenderImage`. Animated
  AVIF/JXL render first frame only (v0.1).

## Placement, outputs, clamping

- New pins are created on the **cursor's output** (hyprctl resolution, as in
  upperadd). Geometry is stored per-output.
- Spawn default size: decoded natural size capped to 50% of the output
  dimensions, aspect preserved.
- **Every pin must be fully on-screen**: clamped at spawn _and_ re-checked
  for all pins at toggle-on (covers resolution/output changes).
- Missing output at boot → its pins stay hidden until it reappears.

## Persistence

- `~/.local/state/impin/pins.toml`, atomic writes (tmp + rename), saved on
  gesture end and content changes. Per pin: source (file path or stored
  image hash), output, x/y/w/h, zoom, pan, opacity, corner radius, z-order.
- Clipboard images (no source file) are written to
  `~/.local/state/impin/images/<blake3>.png` and referenced by hash.
- File pins reference the original path (not copied); a vanished file shows
  a dim "missing" placeholder pin that keeps its slot. Disk changes do not
  live-refresh in v0.1 (fs-watch → v0.2).
- No config file in v0.1 (defaults hard-coded); state file only.

## Platforms

- **Linux x86_64 + aarch64, both GNU (glibc)** — musl is uncharted for the
  gpui wayland/wgpu stack. Arch-container (x86_64) + bare ubuntu-24.04-arm
  (aarch64) CI builds, mirroring the fixed upperadd workflow.
- **Windows**: deferred to v0.2 (owner rarely uses it; the fork also needs a
  topmost patch — `WS_EX_TOPMOST` exists only on `WindowKind::PopUp`).
  Content/platform-neutral core keeps the port cheap.

## Release & packaging (at v0.1.0 tag)

- Public repo `github.com/mdrv/impin` (created when v0.1.0 tags), MIT.
- Release workflow with **latest** `uses:` action versions; assets named
  `impin-<tag>-<rust-triple>.tar.gz` (owner convention, e.g.
  `impin-v0.1.0-aarch64-unknown-linux-gnu.tar.gz`).
- Binary PKGBUILD at `/g/alarm/packages/impin/` consuming release tarballs
  (both arches declared, `update.jsonc` entry, alarm README listing), per
  `/g/alarm/AGENTS.md`.

## Milestones

- **M1 — shell**: scaffold; daemon + socket + verbs; one test pin window
  (layer-shell, click-to-focus, show/hide/toggle); state file skeleton.
  Gate: toggle round-trip + restart restores.
- **M2 — images**: add/clipboard/drop-drag-drop; decode pipeline incl.
  AVIF/JXL; move/resize (poll mechanics); zoom/pan/opacity/radius + keys;
  raise-on-click; on-screen clamping.
  Gate: every interaction verified by the owner; persistence round-trip.
- **M3 — polish + release**: missing-file placeholders, multi-output
  restore, README (+ Hyprland binds: `$mainMod+I` toggle,
  `$mainMod+Shift+I` clipboard), `.desktop`; release workflow, tag,
  PKGBUILD. Gate: AGENTS.md verification green + release published.

## Out of scope (v0.1.0)

Windows, video/frame-pause, live fs-refresh of file pins, per-pin hide,
config file, mouse-only delete, animated AVIF/JXL sequences, cropping/
annotation, sync, systemd unit.
